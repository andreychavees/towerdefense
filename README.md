# Gatos vs Minhoca

Jogo de defesa de torres (tower defense) em HTML5 canvas, estilo cartoon chibi.

- Arraste os gatos para blocos de grama livres ao redor da estrada.
- Una dois gatos iguais para evoluir; no nível 5 escolha entre Evolução (com chance de falha) e Mutação.
- Quebre os potes de vidro para ganhar novos gatos.

## Como rodar

```bash
node server.js
```

Abra http://localhost:8765

## Estrutura

- `gatos-vs-minhoca.html`: o jogo
- `server.js`: servidor estático local
- `assets/art`: arte dos personagens, inimigos e blocos do mapa
- `assets/dragon`, `assets/knight`: pacote "Knight, Princess and Dragon 2" (CC0, OpenGameArt)
